# Security Policy

## Supported Versions

We currently provide security updates for the `main` branch. 

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of CineAI very seriously. If you discover a vulnerability, please do **not** open a public issue.

Instead, please send an email directly to the maintainer:
**sushen.d3v@gmail.com**

Please include the following information in your report:
- The type of vulnerability (e.g., SQLi, XSS, SSRF).
- Full details on how to reproduce the vulnerability.
- Any potential impact on the system, user data, or infrastructure.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to resolve critical issues immediately. Once the vulnerability has been resolved and deployed, you will be credited in the repository's changelog.
